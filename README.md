# Titanic Survival Prediction - Bayesian Optimized GBDT

Kaggle Titanic competition solution using Gradient Boosting with Bayesian Optimization.

## Results

- Validation Accuracy: 82.68%
- CV Accuracy: 83.61%
- Kaggle Public Score: 76.56%

## Files

- `titanic_train.py` - Training script
- `titanic_model.pkl` - Trained model
- `titanic_scaler.pkl` - Feature scaler
- `titanic_features.pkl` - Feature list
- `submission.csv` - Kaggle submission file
